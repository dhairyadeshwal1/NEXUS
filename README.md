# NEXUS 2024 - GeeksForGeeks Bennett Event Landing Page

## Concept
Marvel-themed cinematic event website for GeeksForGeeks Student Chapter's flagship tech conference. 
Designed to feel like a real MCU event announcement, not a college template.

## Key Features
- **Cinematic hero section** with animated entrance
- **Event highlights** with smooth hover animations
- **Timeline schedule** with scroll reveal effects
- **Responsive form** with custom styling
- **Mobile-optimized** - 100% responsive design
- **Performance** - Single HTML file, optimized assets

## Design Inspiration
- Marvel cinematic universe visual language
- References: Awwwards (featured tech company sites)
- Modern gradient design trends
- Dark theme with accent colors

## Technologies Used
- **HTML5** - Semantic structure
- **CSS3** - Animations, gradients, flexbox, grid
- **Vanilla JavaScript** - Scroll reveals, form handling
- **Google Fonts** - Sora (display) + Roboto Mono (accent)

## Resources
- Color Palette: Marvel Brand Colors + Custom Gradients
- Typography: Google Fonts (Sora, Roboto Mono)
- Icons: Unicode Emoji + Custom SVG-style elements
- Animations: CSS Keyframes + Intersection Observer API

## Design Details
| Element | Choice | Why |
|---------|--------|-----|
